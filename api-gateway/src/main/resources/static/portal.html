🎓 Live Presentation Walkthrough Script

1
Open Swagger UI: Navigate to http://localhost:8083/swagger-ui.html. Point out the single unified scrolling view containing all 7 microservices.
2
Register Admin: Expand 1. Authentication Service → Execute POST /api/auth/register-admin with header X-Admin-Setup-Key: AerobookAdminSetup2026. Copy the returned accessToken.
3
Authorize Globally: Click the green Authorize 🔓 button at top right → Paste token → Click Authorize. All requests now pass JWT claims.
4
Fleet Registration: Scroll down to 3. Flight Scheduling Service → Execute POST /api/admin/aircrafts (Airbus A320, 180 seats).
5
Schedule Flight: Execute POST /api/admin/flights (Flight AI101 Mumbai → Delhi).
6
Configure Fares: Scroll down to 4. Fare & Pricing Service → Execute POST /api/fares (Economy ₹4500, Business ₹8500, Tax 18%).
7
Customer Flight Search: Scroll to 3. Flight Scheduling Service → Execute GET /api/flights/search?source=Mumbai&destination=Delhi.
8
Reserve Ticket: Scroll down to 5. Booking & Messaging Service → Execute POST /api/bookings for Asha Khan. Note the generated PNR and RabbitMQ event.
9
Airport Check-In: Scroll down to 6. Airport Check-In Service → Execute POST /api/check-ins for Booking ID 1 (Seat 12A). Observe issued boarding pass BP-1-12A.
10
Demonstrate RBAC Enforcement: Try accessing GET /api/bookings without admin authority to show 403 Forbidden vs with admin authority (200 OK).
